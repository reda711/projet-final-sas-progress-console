"# projet-final-sas-progress-console" 

sas progress console is a javascript app that allows you to manage and track learners and their progress 

the app allows you to :
* add learners
* Display learners
* Search for a learner
* Consult a learner by ID
* Record daily results
* Calculate learner progress
* Filter learners by level
* Sort learners by progress
* Sort learners alphabetically

the app was built using javascript , node js and prompt sync
